# 钻石狂潮浏览器版

GitHub Pages 静态网站，无服务器、无银行卡、无第三方运行时依赖。使用最大熵估值算法（Python 与 JavaScript 对照验证）；夺冠率、平均名次为观测值，亚军、季军和前三率为模型推算，样本数未知时不生成置信区间，提供出价计算、卡包阵容匹配、变阵筛选、装备筛选和本地图标。

主页面通过 static/static-api.js 读取公开数据快照，计算在浏览器本地完成。数据来自万象梯度榜与万象棋大数据公开快照，相关性不代表购买因果收益。匹配结果为候选，不是确定归属或概率。

不买基准先尝试完整拍品加权反推；未覆盖人群不足10%或反推越界时，使用整体最大熵分布作为先验，拟合带KL正则化的软矩约束（冠军指示与归一化名次，平滑强度0.015，按用户的日落海首轮来才约1000建议价经验校准，尚非实测验证）。近似基准用≈标注；拍品权重合计不小于100%时只能采用整体表现参考，无法识别不买人群。该估计依赖模型假设，分布可行范围不包含基准估计误差，也不是置信区间。实际输入缺失或无效时仍停止计算，手动名次情景保持可选。

实测 JSON 导入仅存当前设备/浏览器 localStorage，不会上传或跨设备同步；清除浏览器数据会丢失。快照更新由维护者运行本地 build_pages.py 后提交发布。不提供上游在线刷新。

GitHub Pages：main 分支根目录；包含 .nojekyll，原生静态发布。当前网页文件、算法和快照对公众可见，未发布账号凭据、用户记录或本地备份。
