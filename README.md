# 钻石狂潮浏览器版

GitHub Pages 静态网站，无服务器、无银行卡、无第三方运行时依赖。使用最大熵估值算法（Python 与 JavaScript 对照验证）；夺冠率、平均名次为观测值，亚军、季军和前三率为模型推算，样本数未知时不生成置信区间，提供出价计算、卡包阵容匹配、变阵筛选、装备筛选和本地图标。

主页面通过 static/static-api.js 读取公开数据快照，计算在浏览器本地完成。数据来自万象梯度榜与万象棋大数据公开快照，相关性不代表购买因果收益。匹配结果为候选，不是确定归属或概率。

不买基准先尝试完整拍品加权反推；未覆盖人群不足10%或反推越界时，使用整体最大熵分布作为先验，拟合带KL正则化的软矩约束（冠军指示与归一化名次，平滑强度0.1）。近似基准用≈标注；拍品权重合计不小于100%时只能采用整体表现参考，无法识别不买人群。该估计依赖模型假设，分布可行范围不包含基准估计误差，也不是置信区间。实际输入缺失或无效时仍停止计算，手动名次情景保持可选。

实测 JSON 导入仅存当前设备/浏览器 localStorage，不会上传或跨设备同步；清除浏览器数据会丢失。

更新数据：网页点击“更新数据”打开GitHub，仓库拥有者登录后点击 Run workflow 确认运行（默认勾选刷新）。云端自动抓取大师场最近3天的天赋、装备、英雄、阵容及详情，保留卡包对应关系，卡包和排行完整后保存快照并发布；个别详情不可用会单独标注且不沿用旧统计；网页会等待完成并载入新数据。无需在网页填写或保存GitHub令牌。核心数据抓取失败时保留线上原版；更新前数据备份artifact保留7天，完整旧版可在Git历史恢复。首次更新前需将Pages构建方式设置为GitHub Actions。仅发布源码时的push不会重新抓取上游。

GitHub Pages：由 main 分支的更新与部署工作流发布，包含 .nojekyll。当前网页文件、算法和快照对公众可见，未发布账号凭据、用户记录或本地备份。
